# Binary Search in C++

This repository contains my solutions to approximately **30 Binary Search problems** from the Striver A2Z DSA Sheet, implemented in C++.

The goal is to build a strong understanding of binary search, search-space optimization, and efficient problem-solving techniques used in DSA and technical interviews.

## Topics Covered

* **1D Binary Search**

  * Basic Binary Search
  * Lower Bound and Upper Bound
  * Search in Rotated Sorted Arrays
  * Finding Peak Elements
  * First and Last Occurrences
  * Search Space and Boundary Conditions

* **Binary Search on Answers**

  * Finding the Nth Root of a Number
  * Minimum and Maximum Answer Problems
  * Searching Over a Range of Possible Answers
  * Problems involving optimization and feasibility checks

* **2D Binary Search**

  * Searching in a 2D Matrix
  * Finding Peak Elements in a 2D Matrix
  * Row-wise Binary Search
  * Matrix Median

## Language and Tools

* **Language:** C++
* **Practice Sheet:** Striver A2Z DSA Sheet
* **Platforms:** GeeksforGeeks, LeetCode, and other practice platforms
* **IDE:** Visual Studio Code

## Key Learnings

* Understanding binary search intuition and search-space reduction.
* Choosing correct `low`, `high`, and `mid` boundaries.
* Applying binary search to indices as well as answer values.
* Using sorted properties to optimize searching in arrays and matrices.
* Combining binary search with counting and feasibility checks.
* Handling edge cases and analyzing time and auxiliary-space complexity.

## Complexity

* **Standard Binary Search:** `O(log n)` time
* **Binary Search on Answers:** Depends on the answer range and feasibility-checking cost.
* **2D Binary Search:** Depends on the matrix structure and chosen approach.
* **Auxiliary Space:** Usually `O(1)` for iterative binary search, excluding input storage.
