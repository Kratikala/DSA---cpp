# Linked Lists

> Part of my Data Structures & Algorithms (DSA) journey in C++.

This folder contains my implementation and practice of Singly Linked List
problems from the Striver A2Z DSA Sheet, LeetCode, and GeeksforGeeks.

The focus is on pointer manipulation, recursion, linked-list patterns,
in-place operations, and optimal problem-solving techniques.

## Complexity Overview

| Operation | Time |
|---|---:|
| Traversal | O(n) |
| Search | O(n) |
| Insert at Head | O(1) |
| Delete Head | O(1) |
| Insert/Delete at Position | O(n) |
| Reverse Linked List | O(n) |
| Find Middle | O(n) |
| Detect Cycle | O(n) |
| Merge Two Sorted Lists | O(n + m) |
| Sort List | O(n log n) |
| Sort 0s, 1s and 2s | O(n) |
