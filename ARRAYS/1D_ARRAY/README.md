## Key Patterns

### Two Pointers

Used for problems involving two positions in an array, such as reversing, rotating, and certain pair-based problems.

### Hashing

Used for fast lookup and frequency-based problems.

### Prefix Sum

Used to efficiently identify subarrays based on their cumulative sum.

### In-place Manipulation

Used to modify the array without creating another array, reducing auxiliary space.

### Kadane's Algorithm

Used to find the maximum subarray sum efficiently.

### Sorting-Based Techniques

Sorting can simplify problems involving duplicates, ordering, and element relationships.

## Complexity

Complexity depends on the approach used for each problem.

Common complexities include:

* **Time:** `O(n)`
* **Time:** `O(n log n)`
* **Time:** `O(n²)`
* **Auxiliary Space:** `O(1)`
* **Auxiliary Space:** `O(n)`

> Hashing and prefix-sum approaches may require `O(n)` auxiliary space, while in-place approaches can achieve `O(1)` auxiliary space.
